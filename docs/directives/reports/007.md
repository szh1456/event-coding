## 5. Deviations and incidents

1. **Cost.** 88.3 CPU-hours against 69.6 projected. Most of the excess is in the time
   outside the fits: `c_0` = 18.8 s per group from Stage 0 varied from 0.3 to 112 s over
   the ten groups. Per Section 15, the run was let finish. The spacing stayed S = 90.
2. **Receiver.** In Stage 0 and Stage R the receiver was one separate process, started
   after the stream files were closed. It was given only the directory of stream files,
   and read the events of the recording named in each file name to score.

## 6. Questions for the director

1. **The frozen configuration is at the edge of the grid.** At B = 20, J rises
   monotonically with rho up to the largest density, 1 event per pixel (0.005, 0.033,
   0.063, 0.093, 0.118). At B = 40 it rises up to rho = 1 too. Only B = 80 turns over (at
   rho = 1/2). Fidelity falls along the same direction (Table 4: F at K = 4 from 0.753 to
   0.706 by day). This is the pattern Section 2 saw on synthetic scenes. Should a later
   directive extend the densities above 1, or change the criterion, before the
   configuration is carried to the second dataset?
2. **Translation against affine under coder Q.** At the frozen configuration the
   translation gains slightly more than the affine map with coder Q at every `K`, and
   slightly less with coder T from K = 4 on (equal at K = 2). D-007-1 fixes the affine map. Is that kept for the second
   dataset?
3. **K = 2.** With coder Q the codec loses to the subset envelope at K = 2 (gain 0.92 to
   0.94) and wins from K = 4 on. Should the paper state the group length explicitly with
   this rule?
