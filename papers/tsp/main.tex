\title{Rate--Distortion Analysis of Event Streams from Moving Edges}
\author{[Author list to be set]}
\maketitle

\begin{abstract}
An event camera reports when the log intensity of a pixel crosses a threshold. When an edge moves
across the sensor, the pixels on its path share the edge and its motion, yet each fires on its own
lattice of threshold levels, offset by a threshold phase, and each event carries timing jitter, so the
pixels emit different events. We ask what information the events still hold once the edge and the
motion are known, and which of it a mean-squared timing tolerance allows a code to leave out. For a
ramp edge that passes each pixel once under an affine flow, with independent uniform phases and
Gaussian jitter, the event times of a pixel split into a common shift, which carries the phase, and
relative variations, which carry only jitter. The conditional rate-distortion function follows. Below
the jitter variance every event time must be described, and the rate is exact. Up to
$D_A=\sigma^2+\tau^2/12$, with $\tau$ the event spacing of the pixel, a description of the common shift
alone comes within $0.255$ bit per pixel of the rate. From $D_A$ on the conditional rate is zero, and
the events are regenerated from the edge and the motion. Events moved along the motion keep the phase
of their source pixel, so the event spacing also sets the time bins over which moved counts remain
predictive. A controlled model shows that the phases alone cause the loss of moved counts, a test on
recordings from a static and a moving camera detects no phase lock on regular event trains, and an
HEVC coder on count pictures shows what the mechanism means for a standard coder.
\end{abstract}

\begin{IEEEkeywords}
Event camera, send-on-delta sampling, level-crossing sampling, rate-distortion theory, generalized
sampling, motion compensation, video coding, HEVC, neuromorphic sensing.
\end{IEEEkeywords}

\section{Introduction}
\IEEEPARstart{A}{n} event camera has no frames. Each pixel compares its log intensity with a stored
reference and emits an event, with a time stamp and a polarity, whenever the difference reaches a
contrast threshold \cite{lichtsteiner2008,gallego2022survey}. The output is a stream of
address-events whose rate follows the scene: it is close to zero for a static scene and rises with
the speed and the contrast of what moves. A sensor node that forwards this stream over a
rate-limited link must decide how many bits the stream needs, and a receiver that does not need
every event at its exact time should let it send fewer. How many bits does the stream of a moving
scene need when the receiver tolerates a given timing error?

The stream of a moving scene looks highly redundant. If an object moves across the sensor, the
pixels along the path of one of its edges observe the same intensity profile, one after the other.
Yet they do not emit the same events. Each pixel compares the intensity with its own reference, so
it fires on its own lattice of levels, and the offset of that lattice, the threshold phase of the
pixel, differs from pixel to pixel. The same profile therefore produces a different event train at
every pixel (Fig.~\ref{fig:mechanism}). Moving the events of one pixel to the next along the motion
of the edge removes the delay between the two arrivals, but not the offset between the two lattices
(Fig.~\ref{fig:mechanism}c).

\caption{An edge crosses a row of pixels. (a) Every pixel has levels of the same step and its own

\label{fig:mechanism}
\end{figure}
Which of these differences a code must describe depends on the timing error that the receiver
tolerates.

Existing event coders approach the rate empirically. Lossless coders exploit the spatial and temporal
correlation of addresses and time stamps \cite{bi2018,khan2021talven,schiopu2022spl}. Lossy coders
discard or aggregate events \cite{banerjee2021icip,huang2023icip}, and the coder of
\cite{stumpp2024} suppresses events that an on-sensor optical flow can predict and lets the receiver
extrapolate them. Event streams have also been aggregated into count pictures and coded by HEVC
\cite{khan2021talven,sullivan2012hevc}, a video coder whose prediction is motion compensated
\cite{sullivan1998}. Reported results are hard to compare \cite{brites2025,rezaee2026}. On the
theoretical side, rate-distortion results for point processes concern Poisson and finite point
processes \cite{rubin1974,verdu1996,lapidoth2015,koliander2018}. Sampling theory comes closer to the
mechanism. An event pixel is a send-on-delta sampler \cite{miskowicz2006}, which for a monotone input
coincides with level-crossing sampling \cite{mark1981,martineznuevo2019}, and an object that crosses
$M$ pixels is sampled by $M$ such samplers. This recalls the generalized sampling expansion
\cite{papoulis1977gse} and multi-channel time encoding, where shifted integrate-and-fire encoders
share one input and the shifts make the channels complementary
\cite{lazar2004,adam2020multichannel,adam2022}; the threshold phases play the role of these shifts.
None of these results separates the cost of what the pixels of a path share, the edge and its motion,
from the cost of what each pixel holds privately, and so none says what a timing tolerance allows a
code to leave out.

We model the events of a ramp edge that passes each pixel once under an affine flow, with independent
uniform phases and Gaussian jitter, and give the edge and its motion to the encoder and the decoder.
The event times of a pixel then split into a common shift, which carries the phase and the mean
jitter, and relative variations, which carry only jitter, and the rate-distortion function of the event
times under a mean-squared timing tolerance has three regimes. Below the jitter variance a code must
describe every event time. Up to a threshold $D_A=\sigma^2+\tau^2/12$, set by the event spacing $\tau$
of the pixel, a description of the common shift alone comes within $0.255$ bit per pixel of the rate.
Beyond $D_A$ the rate is zero: the decoder regenerates the events from the edge and the motion. These
are rates given the edge and the motion. When the motion has a fixed number of parameters and must be
described, a description of $O(\ln M)$ nats along a path of $M$ pixels suffices. A sender holds the events and not the edge, and a common substitute is to
move reference events along the motion, as the prediction of a video coder does. A moved event keeps
the phase of its source pixel, and the same event spacing that sets $D_A$ sets the time bins over which
moved counts remain predictive. A controlled model, a phase test on recordings and an HEVC coder test
and illustrate these consequences.

\emph{1) Information structure and conditional rate-distortion function.} Under independent phases
and jitter, the event times of the pixels are conditionally independent given the edge and the motion,
and the lossless code length of their time stamps grows in proportion to $M$
(Theorem~\ref{thm:lossless}). The rate-distortion function of a pixel is exact below the jitter
variance, bounded within $0.255$ bit per pixel up to $D_A$, and zero from $D_A$ on
(Theorem~\ref{thm:pixel}). A path allocates the tolerance over its pixels (Theorem~\ref{thm:path}), and
a motion with a fixed number of parameters can be described with $O(\ln M)$ nats when the template is
known (Proposition~\ref{prop:motion}).

\emph{2) Reusing events along the motion: error and time scale.} For different source and target pixels with
equal event spacings, moved events have twice the timing error of the regenerated ones
(Proposition~\ref{prop:moved}), and on a voxel grid the counts of a source pixel moved along the true
motion reproduce a share of about $\Delta_t/\tau$ of the true counts when the bin is shorter than the
event spacing. A controlled model, with exact motion and equal counts, shows that the phases alone
cause this loss.

\emph{3) Experimental test of the mechanism.} On recordings from a static camera
\cite{verma2024etram} and from a moving car \cite{gehrig2021dsec}, a per-block phase test detects no
lock of moved events on the regular event trains where it can be applied, and a reconstruction shows
what a receiver loses when the timing is left out. An HEVC coder serves as a case for the consequences
on fine time grids.

Section~\ref{sec:model} states the model and the problem. Section~\ref{sec:lossless} gives the
structure of the events, Section~\ref{sec:tolerance} the rate-distortion function, and
Section~\ref{sec:moved} the cost of moved events. Section~\ref{sec:experiments} reports the
experiments. Proofs are in the appendices. Rates are in nats unless bits are named, $\|\cdot\|$ is the
Euclidean norm of a vector and the spectral norm of a matrix, and $[x]^+=\max(x,0)$.

\section{Model}\label{sec:model}
We first state the pixel rule, from which the phase mechanism follows for any scene. We then
specialize to a ramp edge in uniform passage, for which the rates have closed forms. The model leads to
one representation of the events of a pixel (Lemma~\ref{lem:times}): a deterministic train set by the
edge and the motion, shifted by a common phase offset and perturbed by an independent jitter per
event.
\subsection{Pixel}
Pixels sit at the lattice points $i\in\Z^2$ of the image plane. Pixel $i$ observes the log intensity
$\ell_i(t)=L(i,t)$ of a continuous field $L$.

\textbf{(A1) Send-on-delta.} Pixel $i$ holds a reference $\mu_i$ with $|\ell_i-\mu_i|<C$ at the
start. It emits an event at the first time $t$ at which $|\ell_i(t)-\mu_i|=C$, with polarity
$p=\operatorname{sign}(\ell_i(t)-\mu_i)$, and then sets $\mu_i\leftarrow\mu_i+pC$. The contrast
threshold $C>0$ is common to all pixels and known to the decoder. The \emph{phase} of the pixel is
the number $a_i\in(0,C]$ with $\mu_i\in a_i+C\Z$ at the start.

\subsection{Scene and Motion}
A template $g:\R^2\to\R$ gives the log intensity in object coordinates. At time $t$ the object
point $u$ is at the image position $\phi_t(u)=J_tu+b_t$, with $J_t\in\R^{2\times2}$ invertible, so
\begin{equation}\label{eq:field}
  L(x,t)=g\big(\phi_t^{-1}(x)\big)
\end{equation}
and pixel $i$ observes
\begin{equation}\label{eq:traj}
  \ell_i(t)=g\big(u_i(t)\big),\qquad u_i(t)=J_t^{-1}(i-b_t).
\end{equation}
The curve $u_i$ is the trajectory of pixel $i$ in object coordinates. The velocity field
$v(x,t)=\dot\phi_t(\phi_t^{-1}(x))$ is affine in $x$ and satisfies the brightness constancy
relation
\begin{equation}\label{eq:constancy}
  \frac{\partial L}{\partial t}(x,t)+\ip{\nabla L(x,t)}{v(x,t)}=0,
\end{equation}
which follows from differentiating $L(\phi_t(u),t)=g(u)$ in $t$. We call the motion an
\emph{affine flow} when the velocity field is also constant in time,
\begin{equation}\label{eq:flow}
  v(x)=\Lambda x+v_0,
\end{equation}
with generator $\Lambda\in\R^{2\times2}$. A translation has $\Lambda=0$. The trace of $\Lambda$ is
the rate at which the object grows or shrinks in area, its antisymmetric part rotates the object,
and its symmetric traceless part shears it. At a given instant, any smooth velocity field has the
form \eqref{eq:flow} to first order in $x$ around a point, so \eqref{eq:flow} is the local model of
a general motion over a short time.

\subsection{Edge}
\textbf{(A2) Ramp edge.} The template is a ramp across a line with unit normal $\nu$,
\begin{equation}\label{eq:ramp}
  g(u)=\varrho\big(\ip{\nu}{u}-c_0\big),\qquad
  \varrho(z)=\begin{cases}0,&z\le0,\\ \gamma z,&0\le z\le w,\\ V,&z\ge w,\end{cases}
\end{equation}
with slope $\gamma>0$, width $w$ and height $V=\gamma w=nC$ for an integer $n\ge1$.

Pixel $i$ sees the edge through its edge coordinate
\begin{equation}\label{eq:z}
  z_i(t)=\ip{\nu}{u_i(t)}-c_0,\qquad \ell_i(t)=\varrho\big(z_i(t)\big).
\end{equation}
\textbf{(A2$'$) Uniform single passage.} The edge passes pixel $i$ once: $z_i<0$ before a time
$t_i$, $z_i>w$ after the passage, and in between $z_i$ is affine in $t$ with slope $r_i>0$.

Inside the ramp, $\nabla L=\gamma\nu_t$ with $\nu_t=J_t^{-\top}\nu$ a normal of the edge in the
image, and $\dot z_i=-\ip{\nu_t}{v(i,t)}$. By \eqref{eq:constancy}, the intensity of pixel $i$
rises during the passage at the rate
\begin{equation}\label{eq:rate}
  \gamma r_i=-\ip{\nabla L}{v}=\|\nabla L\|\,v_{\perp,i},
\end{equation}
with the field evaluated at pixel $i$. Here $v_{\perp,i}=-\ip{\nabla L}{v}/\|\nabla L\|$ is the
speed at which the edge advances over the pixel along its normal, counted positive when the
intensity of the pixel rises, as it does in a passage with $r_i>0$. We call
\begin{equation}\label{eq:tau}
  \tau_i=\frac{C}{\gamma r_i}=\frac{C}{\|\nabla L\|\,v_{\perp,i}}
\end{equation}
the \emph{event spacing} of pixel $i$. It is the time that the ramp takes to pass the pixel,
divided by $n$. At a fixed image slope $\|\nabla L\|$ it is inversely proportional to the normal
speed of the edge. Assumption (A2$'$) holds exactly for a translation, where $\tau_i$ is the same
for all pixels, and for a plane that approaches the camera along the optical axis at constant
speed, where $J_t^{-1}$ is affine in $t$ and $b_t$ is fixed. For an affine flow it holds to first
order (Remark~\ref{rem:passage}), and $\tau_i$ varies from pixel to pixel.

\subsection{Phase, Jitter and Clock}
\textbf{(A3) Phase.} Before the edge arrives, pixel $i$ rests at the level $0$ with its reference
behind the passage, $\mu_i\in(-C,0]$, so that $a_i=\mu_i+C$. The phases $a_i$ are independent
across pixels, uniform on $(0,C]$, and independent of the jitter.

\textbf{(A4) Jitter and clock.} The $k$th event of pixel $i$ is recorded at
$T_{i,k}=t_{i,k}+\varepsilon_{i,k}$, where $t_{i,k}$ is the time given by (A1) and the
$\varepsilon_{i,k}$ are independent $\mathcal N(0,\sigma^2)$ variables, independent of the phases,
with $\sigma>0$. The stored value is $Y_{i,k}=\delta\lfloor T_{i,k}/\delta\rfloor$ for a clock
resolution $\delta$. The index $k$ of each recorded event is known.

The uniform phase does not arise inside the model, in which every pixel rests at the same level. It
stands for the offsets of real pixels and for their earlier activity. A pixel that the edge crosses
from the high level to the low level is covered by the mirrored assumption, with its reference in
$[V,V+C)$. Remark~\ref{rem:relax} treats a reference that is ahead of the passage.

We write $T_i=(T_{i,1},\dots,T_{i,n})$ and $Y_i=(Y_{i,1},\dots,Y_{i,n})$, and $\mathcal P$ for the
set of pixels that the edge passes during the observation, with $M=|\mathcal P|$. Let
$\eta(a,\sigma)$ denote the differential entropy of the sum of a uniform variable on $(0,a)$ and an
independent $\mathcal N(0,\sigma^2)$ variable. It satisfies
\begin{equation}\label{eq:eta}
  \tfrac12\ln\!\big(a^2+2\pi e\sigma^2\big)\le\eta(a,\sigma)\le\tfrac12\ln\!\big(2\pi e(a^2/12+\sigma^2)\big)
\end{equation}
by the entropy power inequality \cite[Ch.~17]{cover2006elements} and by the Gaussian bound on the
entropy at a given variance \cite[Ch.~8]{cover2006elements}, and $\eta(a,\sigma)-\ln a\to0$ as
$\sigma/a\to0$.

\subsection{Problem}
The encoder and the decoder know the template $g$ and the flow $\phi$, and hence the pixels that the
edge passes, the number $n$ of events of each and their polarity. The index $k$ of every event is
known (A4). The addresses and the correspondence between events are therefore given, and what remains
to be described are the event times. Theorem~\ref{thm:lossless} counts the bits of their time stamps
at the clock resolution $\delta$. Theorems~\ref{thm:pixel} and~\ref{thm:path} count the bits of the
event times under a mean-squared timing tolerance, and their zero rate is a rate given all of the
above. Proposition~\ref{prop:motion} extends them to a flow that must be described, while the decoder
still holds the template. A practical sender holds neither, and Section~\ref{sec:moved} turns to what
it can send instead.

\section{Structure of the Events}\label{sec:lossless}
\begin{lemma}\label{lem:lattice}
Under (A1), for any continuous $\ell_i$, every event of pixel $i$ occurs at a time $t$ with
$\ell_i(t)\in a_i+C\Z$.
\end{lemma}
The lattice $a_i+C\Z$ never changes. The phase is a property of the pixel, set by its history and
not by the edge that passes.
\begin{lemma}\label{lem:times}
Under (A1), (A2), (A2$'$) and $\mu_i\in(-C,0]$ before the passage, pixel $i$ emits exactly $n$
events, all of positive polarity, at
\begin{equation}\label{eq:times}
  t_{i,k}=t_i+A_i+(k-1)\tau_i,\qquad k=1,\dots,n,
\end{equation}
where $A_i=a_i/(\gamma r_i)$. Under (A3), $A_i$ is uniform on $(0,\tau_i]$.
\end{lemma}
Given the template and the flow, the noise-free events of a pixel are thus a function of one
number, its phase (Fig.~\ref{fig:mechanism}a). In the object coordinate, an event is a point of the graph of the profile on the
level lattice of its pixel: the $M$ pixels of a path sample the same profile on $M$ lattices with
independent offsets.
\begin{theorem}[Lossless code length]\label{thm:lossless}
Under (A1) to (A4) and (A2$'$), the vectors $T_i$, $i\in\mathcal P$, are independent given the
template and the flow,
\begin{equation}\label{eq:hT}
  h(T_i)=\frac{n-1}{2}\ln(2\pi e\sigma^2)+\eta(\sqrt n\,\tau_i,\sigma),
\end{equation}
and
\begin{equation}\label{eq:HY}
  H(Y_i\mid g,\phi)=n\ln\frac1\delta+h(T_i)+e_\delta,
\end{equation}
where $e_\delta\ge0$ for every $\delta$, and $e_\delta\to0$ as $\delta/\sigma\to0$, uniformly in
$\tau_i$.
\end{theorem}
When $\sigma\ll\tau_i$ and $\delta\ll\sigma$, \eqref{eq:HY} gives the cost per event
\begin{equation}\label{eq:perevent}
  \frac{H(Y_i\mid g,\phi)}{n}\approx\frac{n-1}{n}\ln\frac{\sigma\sqrt{2\pi e}}{\delta}
  +\frac1n\ln\frac{\sqrt n\,\tau_i}{\delta}.
\end{equation}
One event of each pixel carries the cost of the phase, and the other $n-1$ carry that of the jitter. The code length of
the path is the sum of \eqref{eq:HY} over $\mathcal P$. It grows in proportion to $M$, and neither
term of \eqref{eq:perevent} falls as the path gets longer: a decoder that knows the edge and its
motion exactly still needs \eqref{eq:perevent} for every event. What the pixels of a path share,
the edge and its motion, a code can describe once. What is private to each pixel, its phase and its
jitter, it must describe for each pixel, and \eqref{eq:HY} is that irreducible conditional rate.

\begin{remark}[Several edges]\label{rem:texture}
Theorem~\ref{thm:lossless} counts one edge that passes each pixel once. If further edges of the
same object pass the same pixel, they meet the same lattice, so the phase is paid once per pixel and
not once per edge. With many edges per pixel the cost per event tends to the jitter term
$\ln(\sigma\sqrt{2\pi e}/\delta)$, which does not depend on the path either.
\end{remark}

\section{Rate-Distortion Function}\label{sec:tolerance}
Theorem~\ref{thm:lossless} gives the entropy of time stamps on a clock of resolution $\delta$, and the
results of this section give the rate of a lossy reconstruction of the continuous event times. Both
describe the same structure, the shared edge and motion and the private phase and jitter, but they are
different quantities.
The decoder outputs
$\hat T_i\in\R^n$ for each pixel, and the distortion is the mean-squared timing error
\begin{equation}\label{eq:dist}
  d(T_i,\hat T_i)=\frac1n\|T_i-\hat T_i\|^2 .
\end{equation}
\subsection{One Pixel}
Let $R_i(D)=\inf I(T_i;\hat T_i)$, with the infimum over the conditional laws of $\hat T_i$ that
satisfy $\E\,d(T_i,\hat T_i)\le D$, be the rate-distortion function of the events of pixel $i$. It
is the rate that block codes over many independent passages approach.

The three regimes below come from one decomposition. By Lemma~\ref{lem:times},
$T_i=c_i+A_i\mathbf 1+\varepsilon_i$, with $c_i$ fixed by the template and the flow, $\mathbf 1$ the
all-ones vector and $\varepsilon_i\sim\mathcal N(0,\sigma^2I_n)$. An orthogonal matrix $Q$ whose first
row is $\mathbf 1^{\!\top}/\sqrt n$ maps $T_i-c_i$ to
\begin{equation}\label{eq:XW}
  X_i=\sqrt n\,A_i+\varepsilon^{\parallel}_i,\qquad W_i\sim\mathcal N(0,\sigma^2I_{n-1}),
\end{equation}
with $\varepsilon^{\parallel}_i\sim\mathcal N(0,\sigma^2)$ and $X_i$ independent of $W_i$. The common
shift $X_i$ carries the phase and the mean jitter, and the $n-1$ relative components $W_i$ carry jitter
only. The distortion \eqref{eq:dist} is invariant under this map. A tolerance below $\sigma^2$ therefore
requires all $n$ components; above it, the relative components can be left at their error $\sigma^2$
and only the common shift is described; and once the error of leaving out everything,
$(\operatorname{Var}X_i+(n-1)\sigma^2)/n$, is tolerated, nothing is described. Define
\begin{equation}\label{eq:defs}
  s_i^2=\frac{n\tau_i^2}{12}+\sigma^2,\qquad D_{A,i}=\sigma^2+\frac{\tau_i^2}{12},
\end{equation}
so that $s_i^2=\operatorname{Var}X_i$ and $D_{A,i}=(s_i^2+(n-1)\sigma^2)/n$, and
\begin{equation}\label{eq:gap}
  \Gamma_i=\tfrac12\ln(2\pi e\,s_i^2)-\eta(\sqrt n\,\tau_i,\sigma).
\end{equation}
By \eqref{eq:eta}, $0\le\Gamma_i\le\tfrac12\ln(2\pi e/12)$, which is $0.255$ bit, for every
$\sigma$ and $\tau_i$.
\begin{theorem}[Rate-distortion function of a pixel]\label{thm:pixel}
Under (A1) to (A4) and (A2$'$),
\begin{equation}\label{eq:rdlow}
  R_i(D)=h(T_i)-\frac n2\ln(2\pi eD)\qquad\text{for }0<D\le\sigma^2,
\end{equation}
\begin{equation}\label{eq:rdmid}
  \big[U_i(D)-\Gamma_i\big]^+\le R_i(D)\le U_i(D)\qquad\text{for }\sigma^2<D<D_{A,i},
\end{equation}
\begin{equation}\label{eq:rdzero}
  R_i(D)=0\qquad\text{for }D\ge D_{A,i},
\end{equation}
with
\begin{equation}\label{eq:U}
  U_i(D)=\frac12\ln\frac{s_i^2}{nD-(n-1)\sigma^2}.
\end{equation}
Moreover,
\begin{equation}\label{eq:rdpos}
  R_i(D)\ge\frac{n\,(D_{A,i}-D)}{2s_i^2}\qquad\text{for }0<D\le D_{A,i},
\end{equation}
so that $R_i(D)>0$ for $D<D_{A,i}$.
\end{theorem}
The three regimes have a direct reading. Below the jitter variance, every bit of timing precision
costs a bit, per event: the rate falls by $\log_210=3.32$ bits per event and per decade of the
root-mean-square tolerance $\sqrt D$. Between $\sigma^2$ and $D_{A,i}$, the rate lies between the
bounds \eqref{eq:rdmid}, whose upper bound is attained by describing the common shift $X_i$ alone, so a
scalar description comes within $\Gamma_i\le0.255$ bit per pixel of the optimum. The theorem does not
state that every optimal code describes a scalar; it states that a scalar is enough to within this gap.
From $D_{A,i}$ on, nothing is described. The decoder that attains \eqref{eq:rdzero} outputs the mean times
\begin{equation}\label{eq:regen}
  \hat T_{i,k}=t_i+\big(k-\tfrac12\big)\tau_i,\qquad k=1,\dots,n .
\end{equation}
It \emph{regenerates} the events of the pixel from the edge and the flow. Each regenerated event is
within $\tau_i/2$ of its noise-free time, and the count and the polarities are exact.

Two of these statements extend beyond the ramp. If the noise-free event times of a pixel are any
function of its phase, \eqref{eq:rdlow} holds below the jitter variance with the entropy of the
actual event times, and the smallest distortion at zero rate is
$\tfrac1n\operatorname{tr}\operatorname{Cov}(T_i)$, attained by the mean times. The middle regime,
in which a scalar description comes within $0.255$ bit per pixel of the rate, and the closed forms
\eqref{eq:hT}, \eqref{eq:U} and \eqref{eq:defs} belong to the ramp in uniform passage, where the
phase shifts all events of a pixel by a common time.

The threshold $D_{A,i}$ grows with the square of the event spacing. By \eqref{eq:tau}, a pixel whose
intensity changes slowly has a large spacing and needs a large tolerance before its events can be
regenerated, and a pixel that is crossed quickly needs a small one.

\subsection{Numerical Check}\label{sec:regimes}

Below $\sigma^2$ the numerical rate equals \eqref{eq:rdlow} to within $4\times10^{-6}$ nat.
Between $\sigma^2$ and $D_{A,i}$ it stays inside the band between the bounds \eqref{eq:rdmid} and
\eqref{eq:rdpos}, which is at most $\Gamma_i=0.187$ bit per pixel wide here, against the limit of
$0.255$ bit per pixel. Near $\sigma^2$ the phase is described finely and the rate sits on the lower bound,
which uses its uniform distribution; toward $D_{A,i}$ the description is coarse and the rate meets
\eqref{eq:rdpos}, which uses only its variance. From $D_{A,i}$ on
the rate is zero, and the regenerated events \eqref{eq:regen} of $2\times10^6$ simulated pixels
have the distortion $0.9994\,D_{A,i}$.

The squares are a uniform scalar quantizer with entropy coding, applied to what each regime
describes. On every component of the event times it stays $0.254$ to $0.258$ bit per event above
\eqref{eq:rdlow}, the loss $\tfrac12\ln(2\pi e/12)$ of a uniform quantizer at fine resolution. On the mean event time alone, with
the other components left out, it stays $0.09$ to $0.19$ bit per event above the lower bound up to
$D_{A,i}$. A code that describes every event time, then one number per pixel, then nothing, is
therefore within $0.26$ bit per event of the limit in all three regimes.


\subsection{A Path}
For the $M$ pixels of a path, let the distortion be the average of \eqref{eq:dist} over
$i\in\mathcal P$, and let $R_{\mathcal P}(D)$ be the rate-distortion function of
$(T_i)_{i\in\mathcal P}$ under it.
\begin{theorem}[Rate-distortion function of a path]\label{thm:path}
Under (A1) to (A4) and (A2$'$),
\begin{equation}\label{eq:alloc}
  R_{\mathcal P}(D)=\min\Big\{\sum_{i\in\mathcal P}R_i(D_i):\ \frac1M\sum_{i\in\mathcal P}D_i\le D\Big\}.
\end{equation}
In particular,
\begin{equation}\label{eq:pathlow}
  R_{\mathcal P}(D)=\sum_{i\in\mathcal P}h(T_i)-\frac{Mn}{2}\ln(2\pi eD)\qquad\text{for }0<D\le\sigma^2,
\end{equation}
and $R_{\mathcal P}(D)=0$ if and only if
\begin{equation}\label{eq:pathzero}
  D\ \ge\ \bar D_A=\sigma^2+\frac1{12M}\sum_{i\in\mathcal P}\tau_i^2 .
\end{equation}
If $\tau_i\le\tau_{\max}$ on the path, then for $D\le\bar D_A$
\begin{equation}\label{eq:pathpos}
  R_{\mathcal P}(D)\ge\frac{nM\,(\bar D_A-D)}{2\,(n\tau_{\max}^2/12+\sigma^2)} .
\end{equation}
\end{theorem}
If the tolerance is imposed on every pixel separately, the rate is zero if and only if
$D\ge\max_iD_{A,i}$, and the slowest crossing sets the tolerance. By \eqref{eq:pathpos}, a tolerance
a fixed margin below $\bar D_A$, with $\tau_{\max}$ bounded uniformly in $M$, leaves a rate proportional
to $M$.

\subsection{The Motion}
Theorems~\ref{thm:pixel} and~\ref{thm:path} assume that the decoder knows the flow. We now extend
them to a flow that must be described, while the decoder still holds the template. An error in a speed displaces the regenerated events in
proportion to the distance that the edge has traveled, so a longer path needs the motion to a finer
precision for the same distortion. A parameter of fixed dimension costs only logarithmically more
at a finer precision, and Proposition~\ref{prop:motion} states this in general form.
\begin{proposition}[Description of the motion]\label{prop:motion}
Let the flow depend on a parameter $\theta=(\theta_1,\dots,\theta_q)$ that ranges over a box whose
$j$th side has length at most $L_jM^{\alpha_j}$, and let the mean times
$\bar t_{i,k}(\theta)=t_i(\theta)+(k-\tfrac12)\tau_i(\theta)$ of \eqref{eq:regen} satisfy
$|\partial\bar t_{i,k}/\partial\theta_j|\le S_jM^{\beta_j}$ on the box, for all events of the path,
with constants $L_j,S_j>0$ and exponents $\alpha_j,\beta_j\ge0$ that do not depend on $M$. Then
for every $\xi>0$ the events of the path can be described with average distortion at most
$(1+\xi)\bar D_A$ using
\begin{equation}\label{eq:B}
  B\le\Big(\sum_{j=1}^q(\alpha_j+\beta_j)\Big)\ln M+O(1)\quad\text{nats,}
\end{equation}
where the $O(1)$ term depends on $q$, $\xi$, $\sigma$ and the constants and not on $M$.
\end{proposition}
For a translation along a line with a speed in a fixed interval that excludes zero, $\theta$ holds
the position of the edge, with a range of order $M$ and a sensitivity of order one, and the speed,
with a range of order one and a sensitivity of order $M$, so $B\le2\ln M+O(1)$. The same holds with
finite exponents, and hence $B=O(\ln M)$, for an affine flow whose normal speed is bounded away from
zero on the path and whose duration is polynomial in $M$. The lossless cost of the same events is
the sum of \eqref{eq:HY}, of order $M$, so the ratio of the two grows at least as $M/\ln M$. The
bound \eqref{eq:B} is an achievable cost for a motion with a fixed number of parameters and the stated
ranges and sensitivities, for a receiver that holds the template; it is not a cost for an arbitrary
motion field or for describing the scene.

\begin{remark}[Departures from the model]\label{rem:relax}
\emph{Reference ahead of the passage.} If $\mu_i\in(0,C)$ before a rising passage, as after a
passage of the opposite polarity at the same pixel, the first level that the intensity meets is the
reference itself, which does not fire. The pixel then emits $n-1$ events, and the results hold with
$n-1$ in place of $n$ and $t_i+\tau_i$ in place of $t_i$.
\emph{Height.} If the height of the edge is not a multiple of the threshold, $V/C=n+f$ with
$0<f<1$, pixel $i$ emits $n+1$ events when $a_i\le fC$ and $n$ otherwise. Reproducing the count
exactly costs the binary entropy of $f$ per pixel, and a zero-rate statement then holds only for a
distortion measure that tolerates one unmatched event per pixel, with a modified threshold.
\emph{Sensor.} Noise events, threshold mismatch between pixels, a refractory time and a jitter that
depends on the slope are outside the model, and their effect on the three regimes is not analyzed
here.
\end{remark}

\section{Reusing Events Along the Motion}\label{sec:moved}
The decoder \eqref{eq:regen} needs the edge and the flow. A sender has neither. It has the events.
It could estimate the edge from them, and this paper does not pursue that route. We study a common
substitute: the receiver moves reference events that it already holds along the motion. This is
motion-compensated prediction, the core of a hybrid video coder \cite{sullivan1998,sullivan2012hevc}:
a block of a decoded picture, displaced by a motion vector, predicts a block of the next picture, and
the coder sends the residual. This section gives what a
moved event costs in timing error and in the fidelity of a receiver that counts events.

\subsection{Timing Error}
\begin{proposition}[Moved events]\label{prop:moved}
Let the same edge pass pixel $j$ in an earlier window and a different pixel $i$ later, under (A1) to
(A4) and (A2$'$), and let the motion be exact, so that the $k$th event of pixel $j$ is moved to pixel
$i$ at the time $\tilde T_{i,k}=T_{j,k}+t_i-t_j$. Then
\begin{equation}\label{eq:moved}
  \frac1n\,\E\|T_i-\tilde T_i\|^2=D_{A,i}+D_{A,j}+\frac{4n^2-1}{12}\,(\tau_i-\tau_j)^2 .
\end{equation}
\end{proposition}
For different source and target pixels with equal event spacings the error is $2D_A$, twice that of \eqref{eq:regen}: a moved event carries
the phase and the jitter of its source pixel, and both are independent of those of its target.
Unequal spacings, as under a change of scale, add the last term, which grows with the square of the
number of events per pixel. If the moved events fall on their own pixel, as for an object at rest,
the phases coincide and only the jitter term $2\sigma^2$ remains.

\subsection{Voxel Fidelity}
The timing error \eqref{eq:dist} presupposes that predicted and true events are paired. Receivers
of event streams count events instead, on a voxel grid: the number of events of each polarity in
blocks of $\Delta_x\times\Delta_x$ pixels and in time bins of length $\Delta_t$. A video coder codes
the same counts as pictures. For a reconstruction with voxel counts $c'$ and a true set with counts
$c$, of sizes $N'$ and $N$, the fidelity is
\begin{equation}\label{eq:fid}
  F=\frac{2\sum\min(c',c)}{N'+N}=1-\frac{\sum|c'-c|}{N'+N},
\end{equation}
the share of the events of the two sets that can be paired one to one inside a voxel.

For blocks of one pixel, a train that is long against the event spacing, and a jitter that is small
against the bin, Lemma~\ref{lem:times} gives the fidelity of the regenerated events
\eqref{eq:regen} directly: a bin holds at most one event of each train when $\Delta_t\le\tau_i$, the
offset between the two trains is uniform, and in expectation over the phase
\begin{equation}\label{eq:binfid}
  F=\frac{\Delta_t}{\tau_i}\qquad\text{for }\Delta_t\le\tau_i,
\end{equation}
with $F=1$ at $\Delta_t=\tau_i$. The voxel counts of a pixel are thus reproduced only when the bin
is at least as long as its event spacing, the same scaling as the threshold of
Theorem~\ref{thm:pixel}, for which $\sqrt{D_{A,i}}=\tau_i/\sqrt{12}$ when $\sigma\ll\tau_i$.

Moved events do almost as well on this grid. With equal spacings and no jitter, the $k$th moved
event lies at the offset $\delta=A_i-A_j$ from the $k$th true event, and $\delta$ has the
triangular density $(\tau_i-|\delta|)/\tau_i^2$ on $(-\tau_i,\tau_i)$. Two events at the offset
$x$ share a bin with probability $[1-|x|/\Delta_t]^+$ over the position of the bins. When
$|\delta|>\tau_i-\Delta_t$, a moved event can share its bin with a neighbor of its true event
instead, which has a partner for $n-1$ of the $n$ events of a train. For a train of $n$ events and
$\Delta_t\le\tau_i/2$, the two contributions give
\begin{equation}\label{eq:binfidmoved}
  F=\frac{\Delta_t}{\tau_i}-\frac{\Delta_t^2}{3n\tau_i^2}.
\end{equation}
A voxel grid does not distinguish the events of a pixel, so the doubled timing error of
\eqref{eq:moved} lowers the fidelity only by a term of order $1/n$.

Equation \eqref{eq:binfidmoved} is the expected fidelity of the events of a given source pixel moved
along the true motion. When the bin is
shorter than the event spacing, the count of a pixel is zero or one, which bins hold the ones is
decided by the phases, and about a share $1-\Delta_t/\tau_i$ of the counts remains a residual. When
the bin is long against the spacing, a bin holds whole trains or long parts of them, the offset
$\delta$ moves only the events at their ends, and the moved counts approach the true ones. Prediction
along the true motion therefore removes most of the counts on long bins and few on short ones.
Equation \eqref{eq:binfidmoved} describes one way of reusing events, not a bound for all motion
compensation. It makes three predictions that Section~\ref{sec:experiments} tests: with the motion
exact, the phases alone make moved counts miss; on recordings, the positions of moved events within
the trains of their target pixels show no lock; and a coder that predicts counts along the motion
gains little where $\Delta_t$ is short against $\tau$.

\section{Experiments}\label{sec:experiments}
The experiments test the predictions of Section~\ref{sec:moved} and then follow them into a standard
coder. On the model, a controlled experiment isolates the phase as the cause of the missing counts
(Section~\ref{sec:control}). On recordings, a phase test checks the premise of the mechanism on the
events where it can be measured (Section~\ref{sec:phase-rec}), and a reconstruction shows what a
receiver loses when a code leaves out timing detail (Section~\ref{sec:demo}). An HEVC coder then serves
as a case for what the mechanism means in practice (Section~\ref{sec:hevc}).

\subsection{Protocol}\label{sec:protocol}
\emph{Data.} The recordings from a static camera are the 112 recordings of the training split of
eTraM \cite{verma2024etram}, 61 by day and 51 by night, from a sensor of $1280\times720$ pixels
above a road, with $2.4\times10^{10}$ events. The recordings from a moving camera are the 41
training sequences of DSEC \cite{gehrig2021dsec}, left event camera, $640\times480$ pixels, on a
car, with $3.7\times10^{10}$ events in $2634$~s. Twelve eTraM recordings and five DSEC sequences are
held out for tuning, and the results below are over the other 100 and 36.

\emph{Grids.} Time is cut into windows of $T_0=33.3$~ms and each window into $k$ slices, so
$\Delta_t=T_0/k$. A voxel holds one pixel and one polarity. We use $k\in\{1,3,6,12,32,64\}$, from
$\Delta_t=33.3$~ms to $0.52$~ms. A group is four consecutive windows, taken every $3$~s of an eTraM
recording and every $2$~s of a DSEC sequence.

\emph{Video coder.} The counts of a group form one clip of $4k$ pictures, with the two polarities side
by side in the luma plane and constant chroma. They are coded by x265~3.5 \cite{x265}, an encoder of
HEVC \cite{sullivan2012hevc}, through ffmpeg~4.4.2, in the Main profile at the preset
\texttt{slow}, with one intra picture and P pictures after it, without B pictures, and with adaptive
quantization and the psychovisual options off. In lossless mode the luma is the count. At a constant
quantization parameter (QP) the luma is $16$ times the count, the decoder rounds the luma divided by
$16$, and the intra picture is coded at the QP of the P pictures. Counts are clipped at $15$, which
removes less than $1\%$ of the events for $k\ge3$; clipped events count as lost, and the
Supplementary Material gives the clip on other grids. Every bit of the
stream is counted, parameter sets included. A lossless decode returns the clipped counts, not the
event stream.

\emph{Voxel list.} As a coder without prediction, the voxel list sorts the events of a window by
voxel, writes the gaps between their voxel indices in a variable-length integer code and compresses
the result with Zstandard at level 19 \cite{rfc8878}. It codes the same clipped counts and returns
them exactly.

\emph{Motion task.} In each group, the ten densest squares of $40\times40$ pixels with at least $200$
events in the third window are selected, and the velocity of each is estimated by contrast
maximization \cite{gallego2018cmax} on the true events and on the decoded events. A square counts
as recovered when the two velocities differ by at most one pixel per window, and a square that the
decode leaves without events counts as not recovered.

\emph{Statistics.} Bits are per true event. A recording enters with the sums over its groups. We
report the median over recordings, or the value pooled over recordings with a 95\% interval from a
bootstrap over recordings where one is given. The coder uses one group in $40$ of eTraM and one in
$20$ of DSEC ($42$ recordings by day, $34$ by night and $36$ sequences), and the phase test one
group in five ($55$, $45$ and $36$).

\subsection{The Phase as the Cause: a Controlled Model}\label{sec:control}

\begin{figure}[t]
\centering
\includegraphics[width=\columnwidth]{figs/fig_control.pdf}
\caption{Fidelity of the counts moved along the exact motion on the model, $n=3$, one-pixel voxels,
for $\tau$ from $0.25$ to $8$~ms and every $k$.}

Straight edges cross a sensor of $320\times240$ pixels at six pixels per window, $40$ pixels apart,
for twelve windows, with $n=3$ and $\tau$ from $0.25$ to $8$~ms. Three conditions share the edges,
their arrival times and the number of events of every pixel: phases shared along each path without
jitter, independent phases without jitter, and independent phases with $\sigma=0.05\,\tau$. The
prediction of a window is the counts of the previous window moved by exactly six pixels, so the
motion is exact and only the phases and the jitter can make the counts differ.

With shared phases the moved counts equal the true ones, $F=1$ in all $36$ cells
(Fig.~\ref{fig:control}). With independent phases they follow \eqref{eq:binfidmoved} to within
$4\times10^{-4}$ wherever it applies, and $F$ falls with $\Delta_t/\tau$: at $\tau=1$~ms, from
$0.99$ at $\Delta_t/\tau=33$ to $0.49$ at $0.52$. Jitter changes $F$ by at most $0.016$. Between
$\Delta_t/\tau=1$ and $4$, where \eqref{eq:binfid} would give $1$ for regenerated events, the moved
counts keep $0.80$ to $0.92$, since a moved train still sits at the offset of its source pixel; from
$\Delta_t/\tau=11$ on they keep $0.97$ or more. In this model the phase alone causes the loss.

\subsection{Phases on Recordings}\label{sec:phase-rec}

\centering
\includegraphics[width=0.92\textwidth]{figs/fig_phase4.pdf}
\caption{Moved events on recordings, moving blocks. (a) Mean of $\cos2\pi u_i$ against the spacing of
the target pixel, with 95\% intervals; open grey markers: random times. (b) Histogram of $u_i$ for

On recordings neither the motion nor the event spacing is known, so we test the premise of the
mechanism rather than \eqref{eq:binfidmoved}. For each block of $20\times20$ pixels, the shift that
pairs the most events of window $w-1$ with window $w$ is chosen, and the same shift, with the median
offset between the first moved and the first true event of the pixels of the block, predicts window
$w+1$ from window $w$. A target pixel and polarity is tested when its true events in window $w+1$
hold two consecutive intervals within a factor $1.2$ of each other. With $\tau_i$ the median of such
intervals, the position of the moved events in its train is
\begin{equation}\label{eq:phase}
  u_i=\frac1{2\pi}\arg\Big(\sum_{k}e^{2\pi\mathrm{i}\,p_k/\tau_i}\sum_{l}e^{-2\pi\mathrm{i}\,t_l/\tau_i}\Big),
\end{equation}
over its predicted times $p_k$ and its true times $t_l$. Under (A3), $A_j-A_i$ is uniform modulo
$\tau_i$, so $u_i$ is uniform on $[0,1)$ for any lengths of the trains and any residual time offset of
the motion that is independent of $A_i$. The offset used here is a median over the pixels of a block,
in which the phase of one target pixel enters only weakly; on the model, with the same estimate,
independent phases give a mean Rayleigh statistic of $1.05$ (below). If the pixels of a path shared their phases, $u_i$ would be constant. Pooling $\cos2\pi
u_i$ over pixels detects a lock common to all blocks, but locks at different values in different
blocks would cancel. The Rayleigh statistic of a block of $m$ tested pixels,
\begin{equation}\label{eq:rayleigh}
  Z=\frac1m\Big|\sum_{i}e^{2\pi\mathrm{i}\,u_i}\Big|^2,
\end{equation}
does not depend on the value of the lock: its mean is $1$ for independent uniform $u_i$ and close to
$m$ when the pixels of a block share one. Before the recordings were read, a 95\% interval of the mean
$Z$ below $2$ was set to read as no lock within blocks, one above $5$ as a lock, and anything else as
partial. Blocks with a zero shift are left out, since a pixel moved onto itself keeps its own phase.

For pixels with $\tau_i$ between $0.25$ and $4$~ms, the mean of $\cos2\pi u_i$ lies within $0.006$ of
$0$ in every bin of $\tau_i$ and in all three strata, against $0.91$ to $0.97$ for shared phases on the
model (Fig.~\ref{fig:phase}a). The histogram of $u_i$ is flat (Fig.~\ref{fig:phase}b). Per block,
the mean $Z$ is $1.07$ ($95\%$ interval $1.02$ to $1.13$) by day, $1.09$ ($1.06$ to $1.14$) at night
and $1.22$ ($1.04$ to $1.46$) on DSEC, over $15{,}028$, $6{,}933$ and $44{,}715$ blocks; the same test
gives $63.8$ on the model with shared phases and $1.05$ with independent ones. All three strata
therefore read as no lock within blocks. A small excess over random times remains: their mean $Z$
is $1.00$, and $1.1\%$ to $1.7\%$ of the blocks exceed $Z=\ln100$, against $0.8\%$ to $1.0\%$ for
random times. The tested pixels hold $33\%$, $27\%$ and $27\%$ of the true events of the scored
windows, and those in the band of Fig.~\ref{fig:phase}b hold $29\%$, $20\%$ and $19\%$. The other
events come from pixels without a regular train in the window.

A lock appears at longer spacings: for $\tau_i$ between $8$ and $16$~ms the mean of $\cos2\pi u_i$
reaches $0.10$ by day, $0.35$ at night and $0.39$ on DSEC, and at night already $0.13$ between $4$ and
$8$~ms. That band holds the periods of mains lighting, $8.33$ and $10$~ms, and the lock is consistent
with lamps that modulate many pixels in step, a common cause outside the model.

How weak a lock the test would see is measured on the model. The phases of each path are spread over a
width $w\tau$, from $w=0$, a shared phase, to $w=1$, independent phases, with the spacings either equal
or spread by $20\%$ from pixel to pixel, and the motion and the offset are estimated from the events as
on the recordings (Fig.~\ref{fig:phase}c). With equal spacings the mean $Z$ is $80.5$ at $w=0$ and the
test detects locks up to $w=0.6$; with spread spacings it is $5.1$ at $w=0$ and detects locks up to
$w=0.3$, because a common fraction of unequal spacings is no longer a common time. Against the
intervals of the recordings, a lock narrower than $w=0.92$ by day and at night and $0.79$ on DSEC, or
$0.72$, $0.71$ and $0.54$ with spread spacings, would have given a larger mean $Z$ than was measured. The
model blocks hold $86$ tested pixels, the recordings $76$, $51$ and $60$, and a lock gives a smaller $Z$
on a smaller block, so these widths are an optimistic reading at night and on DSEC. On the selected
regular trains, the recordings thus rule out a lock of the phases along the motion that is concentrated
within about half the spacing or less, and they leave weaker locks open.

On the same pixels, the counts moved along the estimated motion reproduce $0.1$ to $0.4$ of the true
counts on the grid of $T_0/32$, above the $0.06$ to $0.20$ of random times. Count matching alone,
without any timing, would reach $0.48$ to $0.75$ there, and the motion is estimated, so these values
mix the phase with count mismatch and motion error and do not test \eqref{eq:binfidmoved}.

a car that crosses the sensor at $13$ pixels per window by day; a second car, at night at $9$ pixels
per window, gives the same picture. The three codes follow the order of Theorem~\ref{thm:pixel}
without attaining its rates. The first sends every event with its time in bins of $T_0/256$ by the
voxel list. The second moves the events of the previous window along the motion of their block and
corrects them with one number per pixel: the offset of the first true event of the pixel from its
first moved event, rounded to $T_0/64$, or a symbol that deletes them. The third sends only the
motion. The motion of each block is fitted on the window it predicts, so that the lower rows show
what motion cannot carry and not the errors of its estimate.

Over the whole window the three reconstructions are hard to tell apart from the recording: the motion
places the edges of the car where they are. In a slice of $2.1$~ms the moved events fall on other
pixels than the recorded ones, since each pixel fires on its own phase. Of the $4821$ pixels with an
event in the slice, all events reproduce $4816$; the per-pixel correction reproduces $3098$ and adds
$1864$ elsewhere; the motion alone reproduces $2569$ and adds $3981$. All events cost $9.8$ bits per
event by day and $9.5$ at night and keep $F=1$ on the grid of $T_0/32$. The per-pixel correction costs
$2.4$ and $2.7$ bits per event and keeps $F=0.48$ and $0.47$; the motion alone costs $0.04$ and $0.07$
bits and keeps $0.28$ and $0.25$. On the grid of $T_0/3$ the three codes keep $1.00$, $0.73$ to $0.75$
and $0.61$ to $0.64$: the longer the bin against the event spacing, the more of the recording the
motion carries.

HEVC on count pictures has been used to code event streams without loss \cite{khan2021talven}. We use
x265 as a case: it has motion-compensated prediction, a transform and a quantizer, and we can compare
its P pictures with intra pictures, which isolates the gain of prediction, and with the voxel list,
which gives the total cost of a coder without prediction.

\emph{On the model.} x265 codes the counts of Section~\ref{sec:control}, with independent phases,
without loss (Fig.~\ref{fig:hevc}a). At $\tau=1$~ms its P pictures cost $0.14$ bit per event at
$\Delta_t/\tau=33$ and $7.9$ at $0.52$. They undercut the voxel list for $\Delta_t/\tau\ge5.6$, match it
near $2.8$, and cost up to $1.7$ times as much below $1.4$. Against intra pictures only they save a
factor of $2$ to $2.5$ at $\Delta_t/\tau\ge11$ and of $1.1$ to $1.3$ below $1$. The gain of temporal
prediction shrinks where \eqref{eq:binfidmoved} says that moved counts stop predicting the true ones.

\emph{Without loss, on recordings.} The P pictures need about the bits of the voxel list, and more on
fine grids (Table~\ref{tab:lossless}): the ratio of the two is $0.97$ to $0.98$ for $k\le3$, $0.99$
to $1.05$ at $k=12$, and $1.08$ to $1.13$ at $k=64$. Prediction itself still
pays against intra pictures. On eTraM the intra pictures cost $1.1$ to $3.4$ times the P pictures,
increasingly so at fine slices: a static camera leaves pictures almost empty, and the P pictures save
the cost of signaling empty regions, which an intra picture pays anew. On DSEC, where the camera moves,
the intra pictures cost $1.03$ to $1.10$ times the P pictures. The prediction gain thus survives on
fine grids, but it does not make the coder cheaper than a list of the counts. This ordering is a
measurement of these two coders, which also differ in transform, motion search and syntax, and not a
consequence of the theory. It agrees with the mechanism: on fine grids the counts are set by the
phases, which the motion does not carry.

\emph{With loss.} On a fine grid almost all nonzero counts are one: $92\%$ to $99\%$ of the events lie
in voxels of one event at $T_0/64$. The quantizer then removes events instead of coarsening them. At
$T_0/64$ and QP~$20$ or below, $91\%$ to $99\%$ of the errors of a decode are voxels of one event that
it empties, and $1\%$ to $7\%$ are events that it adds. The P pictures lose more of them than intra
pictures at the same QP, so at equal fidelity the intra pictures are as cheap or cheaper: to reach
$F=0.9$ at $T_0/64$ they need $1.00$, $0.89$ and $0.72$ times the bits of the P pictures by day, at night
and on DSEC (Fig.~\ref{fig:hevc}b). On the grid of $T_0/3$, where voxels hold several events, the
quantizer coarsens counts instead, and $F$ stays above $0.82$ down to about one bit per event. The two
grids answer different timing requirements: $F$ on $T_0/3$ ignores timing differences within $11$~ms,
so its curves give the cost of a looser requirement and not that of a better coder.

\emph{The motion task.} Uncoded, the counts on $T_0/64$ let more squares be recovered than those on
$T_0/3$: $75\%$, $86\%$ and $73\%$ against $44\%$, $71\%$ and $50\%$ (Fig.~\ref{fig:task}). As the
rate falls, the decode on $T_0/64$ empties squares, and the recovered share falls to $0.13$ to $0.36$
near one bit per event; by day $49\%$ of the squares are then left without events. On $T_0/3$ the share
stays at its uncoded value at every QP. Below a rate between $1.5$ and $10$ bits per event, depending on
the stratum, the coarse grid therefore serves the task better. Scoring the squares left without events
as failures matters: at QP~$24$ by day the median error is $3.4$ pixels per window over all squares and
$1.4$ over the squares with events.

\section{Conclusion}
The pixels on the path of a moving edge share the edge and its motion, and each holds a threshold
phase and a jitter of its own. Given the edge and the motion, a timing tolerance decides which of these
private quantities a code must describe. The event times split into a common shift, which carries the
phase, and relative variations, which carry jitter. Below the jitter variance every event time must be
described; up to $D_A=\sigma^2+\tau^2/12$ a description of the common shift comes within $0.255$ bit per
pixel of the rate; beyond $D_A$ nothing is described, and for a motion with a fixed number of
parameters a description of $O(\ln M)$ nats replaces one of order $M$. The event spacing sets the scale of the
tolerance needed for regeneration and of the time bins over which motion-aligned events remain
predictive. A sender that moves events along the motion keeps the phase of the source pixel, and a
controlled model shows that the phase alone then makes moved counts miss on bins shorter than the
event spacing. Recordings show no detectable phase lock on the regular trains where the test applies,
and an HEVC coder on count pictures shows the consequences on fine grids: prediction helps against
intra pictures but not against a list of the counts, and lossy decodes remove single events. The
theory points to a sender that estimates the edge from the events and sends it with the motion. Its
scope is a ramp edge in uniform passage, and texture, noise events and threshold mismatch remain to be
modeled.

\section{Remarks on the Model}
\begin{remark}[Accuracy of the uniform passage]\label{rem:passage}
For an affine flow \eqref{eq:flow}, $\dot\nu_t=-\Lambda^{\!\top}\nu_t$ and
$\ddot z_i=\ip{\nu_t}{\Lambda v(i)}$, hence $|\ddot z_i|\le\kappa_i|\dot z_i|$ with
$\kappa_i=\|\Lambda\|/|\cos\vartheta_i|$, where $\vartheta_i$ is the angle between the velocity
$v(i)$ and the normal $\nu_t$. Take $r_i$ as the slope of $z_i$ at $t_i$. Over a passage of
duration $P_i=n\tau_i$, the event times then deviate from \eqref{eq:times} by at most
$\kappa_iP_i^2/2$, to first order in $\kappa_iP_i$. For a generator of norm $0.3\,\mathrm{s}^{-1}$,
a passage of $5$~ms and motion along the normal this is $4\,\mu$s, three orders of magnitude below
the passage time. The bound grows without limit for edges that are nearly parallel to their motion.
Such edges pass few pixels per unit time and contribute few events.
\end{remark}
\begin{remark}[Event count under a change of scale]\label{rem:count}
An edge segment emits $n$ events for every pixel that it passes, so its event rate is $n$ times the
area that it sweeps per unit time, that is $n$ times its length times its mean normal speed. Under
a similarity flow about a fixed point, growth by a factor $\zeta$ makes the segment $\zeta$ times
longer and $\zeta$ times faster, and the rate grows as $\zeta^2$. For an object that approaches at
constant speed, the image speed itself grows as $\zeta^2$ and the rate as $\zeta^3$. A regeneration
that moves a fixed set of events keeps their number. Under a change of scale it must also change
the number of events, or regenerate them from the edge.
\end{remark}
\section{Proofs of Lemmas~\ref{lem:lattice} and~\ref{lem:times}}
\begin{proof}[Proof of Lemma~\ref{lem:lattice}]
The reference starts in $a_i+C\Z$ by the definition of the phase. By (A1) it changes by $\pm C$, so
it stays in this set, and an event requires $\ell_i=\mu_i\pm C$.
\end{proof}
\begin{proof}[Proof of Lemma~\ref{lem:times}]
By (A2) and (A2$'$), $\ell_i$ is nondecreasing, equal to $0$ before $t_i$, to
$\gamma r_i(t-t_i)$ during the passage, and to $V$ after it. Since $\mu_i\le0=\ell_i$ before the
edge arrives and $\mu_i=a_i-C$, the events occur when $\ell_i$ reaches the levels $a_i+(k-1)C$,
$k=1,2,\dots$, as long as the level is at most $V=nC$. Because $0<a_i\le C$, exactly the levels
$k=1,\dots,n$ are reached. Solving $\gamma r_i(t-t_i)=a_i+(k-1)C$ gives \eqref{eq:times}, and
$a_i$ uniform on $(0,C]$ makes $A_i$ uniform on $(0,\tau_i]$.
\end{proof}

\section{Proof of Theorem~\ref{thm:lossless}}
By Lemma~\ref{lem:times}, $T_i=c_i+A_i\mathbf 1+\varepsilon_i$ with $c_i$ a function of the
template and the flow, $\mathbf 1$ the all-ones vector, and
$\varepsilon_i\sim\mathcal N(0,\sigma^2I_n)$. Independence over $i$ follows from (A3) and (A4). Let
$Q$ be an orthogonal matrix whose first row is $\mathbf 1^{\!\top}/\sqrt n$. Then
$Q(T_i-c_i)=(X_i,W_i)$ with
$(X_i,W_i)$ as in \eqref{eq:XW}. The variables $X_i$ and $W_i$ are
independent, because $Q\varepsilon_i$ has independent coordinates and $A_i$ is independent of
$\varepsilon_i$. Differential entropy is invariant under translations and orthogonal maps, so
$h(T_i)=h(X_i)+h(W_i)$, which is \eqref{eq:hT}.

Let $f$ be the density of $T_i$ and $f_\delta$ its average over the cells of the clock lattice. A
cell has probability $\delta^nf_\delta$, so $H(Y_i\mid g,\phi)=n\ln(1/\delta)-\int f\ln f_\delta$
and $e_\delta=\int f\ln(f/f_\delta)$ is a relative entropy, which is nonnegative. The density $f$ is
a mixture over $A_i$ of $\mathcal N(m,\sigma^2I_n)$ densities and $f_\delta$ is the same mixture of
their cell averages. By the joint convexity of relative entropy, $e_\delta$ is at most its largest
value for a single $\mathcal N(m,\sigma^2I_n)$ density, which is $n$ times the value for a scalar
normal density and depends only on $\delta/\sigma$ and on the offset of $m$ in a cell. It tends to
zero with $\delta/\sigma$, uniformly in the offset \cite[Ch.~8]{cover2006elements}.\hfill$\blacksquare$

\section{Proof of Theorem~\ref{thm:pixel}}
The distortion \eqref{eq:dist} is invariant under the translation by $c_i$ and the orthogonal map
$Q$, so $R_i$ is the rate-distortion function of the independent components $(X_i,W_i)$ of
\eqref{eq:XW} under the total squared error $nD$. Their variances are $s_i^2$ and $\sigma^2$, the
latter $n-1$ times. We drop the index $i$ and write $\eta$ for $\eta(\sqrt n\,\tau_i,\sigma)$ and
$\ln^+x=[\ln x]^+$.

\emph{Lower bound \eqref{eq:rdlow} and \eqref{eq:rdmid}.} Let $(\hat X,\hat W)$ have component
errors $d_X$ and $d_1,\dots,d_{n-1}$ with $d_X+\sum_jd_j\le nD$. Independence of the components
gives $I(X,W;\hat X,\hat W)\ge I(X;\hat X)+\sum_jI(W_j;\hat W_j)$. For a Gaussian component,
$I(W_j;\hat W_j)\ge\tfrac12\ln^+(\sigma^2/d_j)$, and
$I(X;\hat X)\ge h(X)-h(X-\hat X)\ge\eta-\tfrac12\ln(2\pi e\,d_X)$. The function
$\ln^+(\sigma^2/d)$ is convex in $d$, so the Gaussian terms are smallest when all $d_j$ equal a
common $d_W$, and $d_W>\sigma^2$ brings no benefit. For $n\ge2$ this gives
\begin{equation}\label{eq:lb}
\begin{split}
  R(D)\ \ge\ \min_{d_W}\Big[&\eta-\tfrac12\ln\!\big(2\pi e\,(nD-(n-1)d_W)\big)\\
  &+\tfrac{n-1}{2}\ln\frac{\sigma^2}{d_W}\Big],
\end{split}
\end{equation}
with the minimum over $0<d_W\le\sigma^2$, $d_W<nD/(n-1)$. The bracket is convex in $d_W$ and its
derivative vanishes only at $d_W=D$. The minimum is at $d_W=D$ when $D\le\sigma^2$, where it equals
the right side of \eqref{eq:rdlow}, and at $d_W=\sigma^2$ otherwise, where it equals $U(D)-\Gamma$.
For $n=1$ there is no $W$ and the same values follow with $d_X=D$.

\emph{Equality for $D\le\sigma^2$.} Write $\varepsilon=\varepsilon'+Z$ with independent
$\varepsilon'\sim\mathcal N(0,(\sigma^2-D)I_n)$ and $Z\sim\mathcal N(0,DI_n)$, and let
$\hat T=c+A\mathbf 1+\varepsilon'$. Then $T=\hat T+Z$ with $Z$ independent of $\hat T$, the
distortion is $D$, and $I(T;\hat T)=h(T)-h(Z)$, which is the lower bound.

\emph{Upper bound for $\sigma^2<D<D_A$.} Spend no rate on $W$, at error $\sigma^2$ per component,
and describe $X$ at error $d=nD-(n-1)\sigma^2\in(\sigma^2,s^2)$ through
$\hat X=(1-d/s^2)(X-\E X+Z')+\E X$, with $Z'$ an independent normal variable of variance
$s^2d/(s^2-d)$. The error is $d$, and $I(X;\hat X)=I(X;X+Z')\le\tfrac12\ln(s^2/d)$, because a
normal input maximizes the mutual information across an additive normal noise channel at a given
input variance \cite{cover2006elements}.

\emph{Lower bound \eqref{eq:rdpos} and zero rate.} For a variable $\Xi$ with
$\ln\E\,e^{\lambda(\Xi-\E\Xi)}\le\lambda^2\varsigma^2/2$ for all $\lambda$ under a law $P$, and any
law $Q$, the nonnegativity of the relative entropy between $Q$ and the law with density
proportional to $e^{\lambda\Xi}$ with respect to $P$ gives
$D(Q\|P)\ge\lambda(\E_Q\Xi-\E_P\Xi)-\lambda^2\varsigma^2/2$, and the best $\lambda$ gives
$(\E_Q\Xi-\E_P\Xi)^2\le2\varsigma^2D(Q\|P)$. With $P$ the law of $X$ and $Q$ its conditional law
given $\hat T$, averaging over $\hat T$ yields
$\operatorname{Var}\,\E[X\mid\hat T]\le2\varsigma^2I(X;\hat T)$. The uniform part of $X$ has width
$a=\sqrt n\,\tau$ and satisfies the condition with $a^2/12$, since
$\ln(\sinh x/x)\le x^2/6$, so $X$ satisfies it with $\varsigma^2=s^2$, and each $W_j$ with
$\sigma^2\le s^2$. Since the conditional mean minimizes the squared error and the components are
independent,
\begin{equation}\label{eq:transport}
\begin{split}
  nD&\ge\E\|T-\E[T\mid\hat T]\|^2\\
  &=nD_A-\operatorname{Var}\,\E[X\mid\hat T]-\sum_j\operatorname{Var}\,\E[W_j\mid\hat T]\\
  &\ge nD_A-2s^2I(T;\hat T),
\end{split}
\end{equation}
which is \eqref{eq:rdpos}. With no description the best output is the mean, which is
\eqref{eq:regen}, at distortion $\tfrac1n(s^2+(n-1)\sigma^2)=D_A$, so
\eqref{eq:rdzero} holds.\hfill$\blacksquare$

\section{Proof of Theorem~\ref{thm:path}}
The vectors $T_i$ are independent and the distortion is additive over $i$. For any $\hat T$ with
average distortion at most $D$, let $D_i=\E\,d(T_i,\hat T_i)$. Then
$I\big((T_i)_i;(\hat T_i)_i\big)\ge\sum_iI(T_i;\hat T_i)\ge\sum_iR_i(D_i)$ with
$\tfrac1M\sum_iD_i\le D$. Conversely, independent test channels whose rates are within any given
margin of $R_i(D_i)$ come within $M$ times that margin of the sum. Each $R_i$ is convex,
nonincreasing and continuous, and tends to infinity as $D_i\to0$ by \eqref{eq:rdlow}, so the
minimum in \eqref{eq:alloc} exists.

For $D<\sigma^2$, every $R_i$ is differentiable at $D$ with the derivative $-n/(2D)$ by
\eqref{eq:rdlow}, and it is convex on $(0,\infty)$. Hence $R_i(D_i)\ge R_i(D)-\tfrac{n}{2D}(D_i-D)$
for every $D_i>0$, and summing over $i$ with $\sum_i(D_i-D)\le0$ shows that the allocation
$D_i=D$ is optimal. This gives \eqref{eq:pathlow} for $D<\sigma^2$, and the case $D=\sigma^2$
follows by continuity.

By Theorem~\ref{thm:pixel}, $\sum_iR_i(D_i)=0$ if and only if $D_i\ge D_{A,i}$ for every $i$, and
such an allocation with average at most $D$ exists if and only if
$D\ge\tfrac1M\sum_iD_{A,i}=\bar D_A$. Finally, \eqref{eq:rdpos} and $s_i^2\le n\tau_{\max}^2/12+\sigma^2$
give $\sum_iR_i(D_i)\ge n\sum_i[D_{A,i}-D_i]^+/(2(n\tau_{\max}^2/12+\sigma^2))$, and
$\sum_i[D_{A,i}-D_i]^+\ge M(\bar D_A-D)$, which is \eqref{eq:pathpos}.\hfill$\blacksquare$

\section{Proof of Proposition~\ref{prop:motion}}
Divide side $j$ of the box into the smallest number of equal cells of length at most
$\varsigma_j=\sqrt{\xi}\,\sigma/(q\,S_jM^{\beta_j})$, and let $\hat\theta$ be the center of the cell
that contains $\theta$. Side $j$ has at most $L_jM^{\alpha_j}/\varsigma_j+1$ cells, so the index of
$\hat\theta$ takes $\sum_j\ln\!\big(L_jS_jq\,M^{\alpha_j+\beta_j}/(\sqrt\xi\,\sigma)+1\big)$ nats,
which is \eqref{eq:B}. The decoder outputs $\hat T_{i,k}=\bar t_{i,k}(\hat\theta)$. The segment
from $\theta$ to $\hat\theta$ lies in the box, so by the mean value theorem
$e_{i,k}=\bar t_{i,k}(\theta)-\bar t_{i,k}(\hat\theta)$ satisfies
$|e_{i,k}|\le\sum_jS_jM^{\beta_j}\varsigma_j/2\le\sqrt\xi\,\sigma/2$. By \eqref{eq:times},
$T_{i,k}-\bar t_{i,k}(\theta)=A_i-\tau_i/2+\varepsilon_{i,k}$ has mean zero given $\theta$ and
variance $D_{A,i}$, and $e_{i,k}$ is a function of $\theta$. Hence
$\E\,(T_{i,k}-\hat T_{i,k})^2=D_{A,i}+\E\,e_{i,k}^2\le D_{A,i}+\xi\sigma^2/4$, and the average over
the path is at most $\bar D_A+\xi\sigma^2/4\le(1+\xi)\bar D_A$.\hfill$\blacksquare$

\section{Proof of Proposition~\ref{prop:moved}}
By \eqref{eq:times} and (A4),
$T_{i,k}-\tilde T_{i,k}=(A_i-A_j)+(k-1)(\tau_i-\tau_j)+\varepsilon_{i,k}-\varepsilon_{j,k}$.
The phases and the jitter of the two pixels are independent, so this difference has the mean
$(k-\tfrac12)(\tau_i-\tau_j)$ and the variance $\tau_i^2/12+\tau_j^2/12+2\sigma^2=D_{A,i}+D_{A,j}$.
Its mean square is the variance plus the squared mean, and
$\tfrac1n\sum_{k=1}^n(k-\tfrac12)^2=(4n^2-1)/12$.\hfill$\blacksquare$
